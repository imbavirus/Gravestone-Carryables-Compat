# Gravestone Carryables 1.0.0

Initial release for NeoForge 1.21.1.

## Features
- Re-equip **Curios** slots when recovering a Gravestone
- Re-equip **Accessories** slots (Aether gloves, rings, etc.)
- Restore vanilla main / armor / offhand to original indices
- Preserve full ItemStack data (backpack contents, enchants, components, modules)

## Config
- `blacklisted_items`, `transfer_cursed_items`
- `restore_curios`, `restore_accessories`, `restore_vanilla_slots`

## Credits
Based on **Leclowndu93150**'s [Corpse-Gravestone-Curios-Compat](https://github.com/Leclowndu93150/Corpse-Gravestone-Curios-Compat) / Gravestone x Curios API Compat. Expanded for Accessories and broader carryables by Infernos.

## Dependencies
- Required: GraveStone, BaguetteLib, NeoForge 1.21.1
- Optional: Curios API, Accessories
